# PostgreSQL

## Описание

Проект предназначен для установки PostgreSQL в одном из двух режимов:
- `Single Instance` - один сервер PostgreSQL
- `High Availability` - высокодоступный кластер Patroni с 2 балансировщиками нарузки HAProxy и заданным в extra-vars количеством серверов PostgreSQL

Предполагается, что пакеты для установки доступны без дополнительной настройки репозиториев.

## Переменные

Проект предполагает запуск со следующими дополнительными переменными (`--extra-vars`):
- `deployment_option` - вариант развертывания. Значения: строка, 'single-instance' или 'high-availability'
- `postgres_version` - версия PostgreSQL. Значения: число, рекомендуется от 16 до 18
- `perform_migration` - выполнить миграцию схемы после установки базы данных. Значения: булево, `True` или `False`
- `migration_script` - миграционный скрипт, который будет выполнен при `perform_migration` = `True`. Значения: строки, файл со скриптом
- `admin_password` - пароль, который будет установлен администратору базы данных (пользователю `postgres`). Значения: строка

## Запуск проекта

Перед запуском проекта необходимо выполнить команду по установке зависимостей:
```Bash
ansible-galaxy install -r requirements.yml
```

После установки зависимостей можно запустить проект. Точкой входа является файл `postgres-docker.yml`.
