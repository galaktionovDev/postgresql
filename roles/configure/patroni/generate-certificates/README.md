# Generate certificates

## Description
A role to generate certificates for etcd and PostgreSQL. The Certificate Authority for certificates may be either self generated by the role or user provided.

In case CA is user provided, `generate_ca` default variable must be set to `false` and `ca_private_key_path`, `ca_certificate_request_path` and `ca_certificate_path` variables must be provided to role.

## Input variables

This role uses the following variables, that intended to be overriden:
- `generate_ca` - whether to generate CA files (private key, certificate request and ca itself) or use user provided, possible choices are `true` and `false`. The default is `true`

#### The following variables are applied only in case `generate_ca` is `false`

- `ca_private_key_path` - path to CA private key on Ansible control node in case it is user provided, e.g. `/usr/lib/ssl/ca.key`. The default value is not set. An error will interrupt playbook execution in case this variable is not set **and `generate_ca` is set to `false`**.
- `ca_certificate_request_path` - path to CA certificate request on Ansible control node in case it is user provided, e.g. `/usr/lib/ssl/ca.csr`. The default value is not set. An error will interrupt playbook execution in case this variable is not set **and `generate_ca` is set to `false`**.
- `ca_certificate_path` - path to CA certificate on Ansible control node in case it is user provided, e.g. `/usr/lib/ssl/ca.crt`. The default value is not set. An error will interrupt playbook execution in case this variable is not set **and `generate_ca` is set to `false`**.

#### The following variables are applied only in case `generate_ca` is `true`

- `certificate_request_C` - country of the certificate. The default is `RU`
- `certificate_request_ST` - state of the certificate. The default is `Moscow`
- `certificate_request_L` - locality of the certificate. The default is `Moscow`
- `certificate_request_O` - organization of the certificate. The default is `Org`
- `certificate_request_OU` - organizational unit of the certificate. The default is `OU`
- `certificate_request_CN` - common name of the certificate. The default is `etcd`.

  > Take a note that the resulting common name is formed like following template:
    ```
    {{ certificate_request_CN }}-{{ hostvars[item].ansible_host }}
    ```
